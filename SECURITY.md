# Security

Please report a vulnerability in this SDK privately to
[support@pipsocket.com](mailto:support@pipsocket.com), not in a public issue. Say what you found
and how to reproduce it. We will answer within two working days.

Never put an API key, an account id that isn't the docs' example, or anything from your account
in an issue, a pull request or a test. If a key may have leaked, roll it on the dashboard's
**API key** page straight away.
